# bench/ — бенчмарк «мозг v2 vs альбом владельца» (issue #20, фаза 2)

| Файл | Что это | Правится руками? |
|---|---|---|
| `briefs-12.json` | 12 треков VELVET STATIC: русская задумка (`ruBrief`), строка промта владельца (`referenceTrackLine`), BPM | да (вход бенчмарка) |
| `lyrics-12.json` | лирика владельца (ветка `brain-v2-reference`), общий вход для A и B | нет (из референса) |
| `prompts-12.json` | собранные caption A и B + слои B + самопроверка | нет (генерируется) |
| `out/` | `track-NN-x.wav`, `track-NN-y.wav` — обезличенные дорожки | нет (генерируется) |
| `KEY.md` | ключ: какая версия в x, какая в y | нет (генерируется, **не открывать до голосования**) |

## Сборка промтов

```bash
node tools/bench-captions.cjs
```

Собирает `prompts-12.json` и печатает таблицу сравнения; её расшифровка —
`audits/brain-v2/BENCH-PROMPTS.md`.

## Генерация A/B

Нужен доступ к media-bff (контракт — `server-contract/README.md`,
`POST /jobs` → `GET /jobs/{id}` → `GET /files/{id}`). Из сэндбокса агента стенд
недостижим, поэтому генерация — за владельцем/координатором:

```bash
node tools/bench-ab.cjs --dry-run        # план и распределение x/y
MEDIA_BFF_URL=https://… MEDIA_BFF_TOKEN=… node tools/bench-ab.cjs
```

Параметры по умолчанию: `model=ace-step-pro`, `duration=150`, `format=wav`,
строго последовательно (x, затем y для каждого трека), `language=en`.
Переопределяются через `BENCH_MODEL`, `BENCH_DURATION`, `BENCH_SEED`.

## Обезличивание

Отличие от буквы issue §7.3 (там `bench/A/` и `bench/B/`): папки A/B сами по себе
раскрывают, где чья версия, поэтому обе дорожки лежат в одной `bench/out/` с
именами `track-NN-x.wav` / `track-NN-y.wav`. Соответствие — только в `KEY.md`.
Направление x/y для каждого трека выбирается детерминированно от `BENCH_SEED`,
так что «x = владелец» не угадывается по порядку.

## Как голосовать

1. Слушать пары подряд: `track-01-x`, `track-01-y`, … `track-12-x`, `track-12-y`.
2. По каждому треку выбрать: x / y / ничья.
3. Только после этого открыть `KEY.md` и посчитать счёт.
4. Результат — в issue #20: сколько пар забрал мозг v2 и на каких слоях
   референс выиграл.
