# Поставка: feat(#35) — компактный чат-UI, редкое за «⋯» и бургером

**Ветка:** `feat/compact-chat-ui` · **База:** `fix/chat-draft-brain` (8a3e423) · **Коммит:** e7e33be
**Задачи:** briix-studio#35 (UI v2 — фокус на создании музыки), запрос владельца 21.11:
«блок ввода и настройки занимают почти половину экрана — переработать полностью,
редкое убрать в профиль/меню/бургер; мозг должен работать» (мозг — ветка fix/chat-draft-brain).

## Что сделано

Замер до (390×844): композер ≈ 380px из 844 (~45% экрана) — режимы, поле rows=2,
строка продюсера, тулбар из 8 чипов в 2–3 ряда, мета, нижняя панель вкладок.
Замер после: **композер 212px (~25%), лента 575px (68% экрана)**; на десктопе 195px.

Композер — на лице только частое:

- тулбар музыкального режима: `[Наставник ▾] [⋯] [отправить]`; фото: `[✨][↩][Наставник][отправить]`;
- «⋯»-панель «Ещё» (один тап, `moreBtn`/`morePanel`, роль group): Модель (с вложенным
  меню), Режим трека (Песня/Инструментал), «Тонко настроить», «Сгенерировать трек»,
  «✦ Подготовить песню» + пояснение продюсера; в фото панель скрыта целиком;
- бургер в шапке (id `profileBtn` сохранён): ник, Новый чат, История, Ключ доступа,
  Выйти, Выйти и очистить; меню открывается вниз (`.menu-down`);
- вкладки Чат/Библиотека — компактный сегмент в шапке (`header-tabs`), нижняя панель
  вкладок удалена (+52px ленте); на ≤480px у бренда прячется слово «Студия»;
- режимы Музыка/Фото — компактный сегмент (2 колонки, 30px), «Создание музыки» → «Музыка»;
- единое поле rows=1 с авто-ростом (`autoGrowPrompt`, потолок прежние 200px);
- мета-полоса — только честный `#status` (левая подпись «домен · режим · наставник»
  убрана как дубль чипа наставника);
- вложения-заглушка «скоро» (`addBtn`) убраны из UI;
- механика меню: `closeMenus(root)` — вложенное меню моделей не схлопывает «⋯»-панель;
  выбор «Песня/Инструментал» и действия закрывают панель, клик по полю закрывает
  через document-listener (панель не перекрывает ввод).

F-39 (докрутка, попутный фикс найден при приёмке): клик по пилюле «↓ N новых» теперь
докручивает к новому низу, когда ленивое медиа растянуло ленту ПОСЛЕ скролла
(`reStick`: MutationObserver 900мс + таймер, порог 140px; restore-скролл докрутку
не вооружает). Тест ждёт оседания состояния до 4с вместо мгновенного среза.

A11y сохранено: тач-таргеты 44px (F-36) везде, включая сегмент в шапке и «⋯»-панель
(отдельная строка в coarse-pointer-медиа); роли/aria-label сохранены у всех
перемещённых контролов (id не менялись); Escape/клик-мимо закрывают панели.
