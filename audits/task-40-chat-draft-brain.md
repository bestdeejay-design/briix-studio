# Поставка: fix(#40) — чат-черновик идёт через слоевой buildCaption

**Ветка:** `fix/chat-draft-brain` · **База:** `origin/main` (118766e) · **Коммит:** 8a3e423
**Задача:** briix-studio#40 («промт только через мозг» — верх волны 2, находка владельца 20.11)
**Связанная:** briix-studio#35 (UI v2), поставляется под веткой `feat/compact-chat-ui` поверх этой.

## Что сделано

Корень (#40): ветка `snapshot.advanced && isAsciiOnly(style)` в `createMusic` отправляла
готовый английский промт наставника в модель одной строкой — слоевой `buildCaption`
(роли/микс/форма/глубина/атмосфера, ≤640) в чат-сценарии не применялся.

Механика (только `studio.js`, мозги не переписаны):

- `session.draft.brainPending` — метка «строка пришла от мозга»: ставится приёмом
  черновика наставника (`renderMusicDraftContent.writeFields`), продюсерского черновика
  (accept и generate-пути) и результатом «✨ Улучшить» для поля стиля;
- снимается: ручной правкой `#musicPrompt` (listener, как у `styleFamily`), откатом
  «Вернуть как было» (наставник/продюсер), `undo('musicPrompt')`, «Повторить с правками»;
- `createMusic`: `advanced + ASCII + brainPending` → `mergePromptTags(строка, brain.tags)`
  — строка наставника остаётся входом и первой в сборке, слои добавляются к ней;
  авторская ASCII-строка (метки нет) уходит как есть — правило #109 сохранено;
- честная плашка в карточке трека: «Промт собран мозгом: N слоёв» (`brainLayerCount`
  по `layers` из `buildCaption`, без правок music-brain.js); плашку носят все
  мозговые пути (перевод, quick-path, лирика-только), не только чат-черновик;
- `input.brainLayers` персистится в фиде сессии — плашка видна после перезагрузки.
