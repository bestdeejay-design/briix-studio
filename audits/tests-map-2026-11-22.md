## ХРОНОЛОГИЯ ОПЫТОВ + АРТЕФАКТЫ + ФАКТЫ

### Ночь 21→22.11: механики промтов на ace-step (12 находок)
Все детали: audits/prompt-mechanics-findings.md. Кратко:
- №1 длительность < длины лирики → вокал плывёт (D1 90с вердикт «что-то мешает»)
- №2 300с безопасно (RU вокал держится); астериксы *…* ПОЮТСЯ → [SFX]
- №3 швы секций → решаются [Transition] брекетами (решение владельца)
- №4 порядок весов: первые ~100 симв caption = темп/стиль (Тысячи окон v1 медляк → v2 ритм-первым = джангл вернулся)
- №5 плотность брекетов: EN-брекеты работают («эффекты суперские»), RU-брекеты — нет (№12)
- №6 generic-хвост слоёв = главный дефект; стилеспецифичные слои решают (Космос v2 «крутая»)
- №7 дрейф регистра куплет→припев; «belt/sustained» запрещены; замки «throughout the entire song»
- №8 гендер-токен не гарантируется (Космос v2 крутая, но вокал женский)
- №9 пустое интро лечится «vocals enter immediately»
- №10 RU + ≥150 BPM = десинк (лимит ace 5Hz); «эффекты суперские — так был бы супер-хит»
- №11 гендер-инструкции в брекетах РАЗРУШАЮТ генерацию («плёнку зажевало»)
- №12 БРЕКЕТЫ НА ЯЗЫКЕ ЛИРИКИ ПОЮТСЯ — брекеты всегда EN
- Победный рецепт ace «низкий бас+хрип»: sub-bass chest rumble + growl + whiskey rasp + no-falsetto-locks + инструментал под голос

### Форматные факты
- MiniMax native 32kHz → CLI отдаёт 44.1kHz (ресемплинг внутри; кандидат на «плёнку»)
- YuE2 native 48kHz stereo — без ресемплинга
- mux не режет динамику: WAV −11.1 LUFS / M4A −11.2, LRA 8.4 идентично
- владелец не слышит разницы mp3/m4a/wav → доставка m4a-only
