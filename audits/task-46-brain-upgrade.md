## Правило 0 владельца (vocal-profile-vocabulary.md, 22.11)

«Тонкие мужские голоса запрещены: в мужских VOCAL_PROFILE никогда не использовать
thin/light/breathy/high tenor/falsetto; всегда chest register / full / warm / wide
chesty timbre; при сомнении — ниже и тяжелее» — применено и залочено тестом:
- tech house: thin vocals → chest voice
- edm: boyish tenor → full chesty tenor
- synthwave: falsetto accents убран (замена — melodic pop phrasing), bright → warm
- trap: nasal → warm (современный цвет сохраняет autotune-light polish)
Тест секции 16 сканирует ВСЕ мужские профили на запрещённые токены веса
(«autotune-light» — лёгкий автотюн, не лёгкий голос: границы слова не пускают ложную тревогу).

## Детали реализации

- **Семь осей** (`VOCAL_AXIS_WORDS`): RU+EN ключи; оси 1/3/4 наследуют боевые словари
  VOCAL_GENDER/TEXTURE/DELIVERY, оси 2/5/6/7 новые (сопрано/альт/тенор/баритон;
  рык/скрим/вибрато/стаккато; весёлый/дерзкий/злой/соблазнительный; dry upfront/
  doubled/harmonies/wide reverb/autotune-light/radio-polished). Ключи, лазящие в чужие
  смыслы без контекста голоса («мощный бас», «звонкий бубенец»), — только при названном
  голосе (GUARDED_AXIS_WORDS).
- **Противоречия** (правило 3): raspy+smooth, growl+breathy — семейный токен уступает
  авторскому; профили всех 23 семей проверены тестом на внутреннюю совместимость.
- **Нейтраль** (правило 6): семья не распознана и автор промолчал → «clean tone +
  dry upfront vocal» вместо generic-хвоста.
- **Бейджи** (правило 5): «Голос задан характеристиками: N признаков (свой выбор)» /
  «Голос из стиля: <семья>» / «Голос: нейтральный профиль» + «Аранжировка размечена:
  N секций» / «Аранжировка автора: N секций с эффектами» — в мета-блоке карточки трека.
- **Попутный фикс:** «live live drum groove» — слово характера, с которого начинается
  грув, больше не дублируется; пустой набор прилагательных не даёт ведущий пробел.
- **Компактный путь (legacy 240):** блок голоса ужимается умно — сначала уходят
  нейтральные заполнители, антифальцетный страж не режется никогда.
