# `audits/repro` — как повторить динамическую часть аудита

Это **копия симулятора**, на котором получены все пометки «Доказано A#» в отчёте
[`audits/audit-full-arena-2026-11.md`](../audit-full-arena-2026-11.md).
Симулятор не является частью рантайма студии и ничего в `studio/` не меняет: файлы студии читаются как есть
и исполняются в окне jsdom, сеть подменяется фейковым `media-bff`, собранным по контракту
`server-contract/` (`bff.py` + `README.md`). Реальные HTTP-запросы не уходят, браузер не нужен.

## Запуск

```bash
cd audits/repro
npm i                 # jsdom + fake-indexeddb (node_modules в git не попадает)
npm run all           # всё подряд; протоколы пишутся в ../evidence/
```

По отдельности:

| Команда | Что делает | Куда пишет |
|---|---|---|

| `node audit-dynamic.cjs A11 A16` | только выбранные сценарии | то же |
| `node audit-static.cjs` | **S1…S4**: пулы фраз ожидания и лексика, контраст токенов палитры (WCAG 2.2), тач-таргеты из CSS, мёртвые правила, метрики кода, состав и дыры тестовых сюит | `../evidence/static-evidence.txt` |

## Файлы

- `harness.cjs` — ядро: jsdom-окно, полифиллы (`crypto.subtle`, `IntersectionObserver`, `ResizeObserver`,
  `MutationObserver`, `canvas`, `HTMLMediaElement`, `URL.createObjectURL` с подсчётом, `fetch` → фейковый bff,
  SSE-ридер), фейковый bff (джобы, стадии, файлы, пики, чат, 401/422/429/503), хелперы
  `boot/login/click/setVal/key/settle/tick/txt/visible`.
  Опции `boot(opts)`: `storage`, `url`, `chatScript`, `chatChunkDelay`, `peaksShape` (`array`|`object`),
  `stages`, `serverList`, `failPollOnce`, `failStatus`, `failEnvelope`, `getJobExtra`, `listExtra`,
  `files`, `timeScale` (ускорение таймеров), `idb` (общая фабрика IndexedDB для сценариев с reload),
  `confirm` (замена нативного диалога).
- `audit-dynamic.cjs`, `audit-static.cjs`, `micro.cjs`, `dbg-*.cjs`, `smoke.cjs` — сценарии.
- `package.json` — зависимости симулятора (только `jsdom`, `fake-indexeddb`).

## Ограничения метода (важно при чтении отчёта)

jsdom не реализует CSS-каскад, воспроизведение медиа, WebAudio, настоящий `canvas`, нативные диалоги и
сетевой стриминг — всё это либо полифиллено, либо проверялось статически. Поэтому в отчёте:

- стилевые и геометрические выводы помечены как статанализ/расчёт (их в реальном браузере перепроверяет
  [`../screens-audit/capture.cjs`](../screens-audit/capture.cjs));
- выводы про одновременное воспроизведение, отрисовку волн и тайминги анимаций помечены «по коду»;
- фактические числа (состав тел запросов, количество узлов, счётчики objectURL/интервалов/обсерверов,
  объём хранилища) — настоящие, они получены исполнением кода студии.

Прогоны недетерминированы в двух местах: ротация фраз ожидания (пул выбирается случайно) и тайминги
(`260 мс` / `1498 мс` в A11 — это диапазон, а не константа). Всё остальное воспроизводится один в один.
