# Поставка: #45 (этап обогащения) — 116 стилевых семейств из dj1-ресёрча закодированы в мозг

**Ветка:** `work/45-style-coding` · **База:** `main` (fad2c34)
**Задача:** этап «обогащение стилями» из дорожной карты мозгов — кодирование
ресёрч-пакета `audits/style-research/` (116 семейств, батчи 0/A…I, PR #54)
в боевые словари. Паритет семей: **26 → 142**.

## Метод: генератор, а не правки руками

`tools/gen-style-pack.cjs` (новый) читает `index.json` + `families/*.md`
(сплит atmosphere на devices/depth живёт только в .md) и перезаписывает
маркированные блоки `// ==== BEGIN/END STYLE PACK (#45) ====`:

- **music-brain.js** — `const STYLE_PACK = {families, genreWords, aliases,
  rhythm, production, atmosphere, vocal, brackets}` + слияние в боевые словари
  (`GENRE_WORDS.push`, `Object.assign` на STYLE_ALIASES / RHYTHM_BY_GENRE /
  PROD_BY_GENRE / STYLE_ATMOSPHERE / VOCAL_PROFILES / BRACKET_GROUPS);
- **producer-brain.js** — `STYLE_FAMILIES.push(...116 имён)` (список наставника).

Идемпотентен (`--check` — проверка свежести, звётся из check-music-brain);
валидирует пакет теми же правилами, что и тесты: правило 0 владельца, запрет
противоречий (VOCAL_CONTRA_PAIRS), ASCII, полнота осей who/timbre/power/
guard/mood, группы брекетов, ритм char/groove/kit. Правки данных — только в
карте правок генератора, с причиной у каждой (см. ниже).

Вышло: 116 семейств, 315 жанровых ключей, 192 алиаса.

## Кодировочные правки (карта генератора, каждая с причиной)

| Правка | Причина |
|---|---|
| `güira` → `guira` (cumbia, 4 вхождения) | контракт ASCII для caption |
| снят RU-алиас «ария» (opera) | подстрока внутри «Мария» — частая тема песни |
| снят RU-алиас «марш» (march) | подстрока внутри «маршрут» — ложный жанр |
| снят RU-алиас «ска» (ska) | «сказка/скала/скамейка» начинаются с «ска» |
| RU-стем «опера» → «оперн» | «операция» ловилась подстрокой |
| снят EN-алиас `fusion` (jazz fusion) | подстрока внутри «confusion» |
| снят EN-алиас `nü metal` (nu metal) | не-ASCII ключ |
| timbre-заполнение: post-punk `thick midrange timbre`, gothic rock `warm timbre`, opera `bright timbre` | 3 профиля пришли без оси тембра (тест требует), стем — жанровая практика соседних семей |
| спор общих алиасов: `psytrance` → psytrance (имя), `goa trance` → trance (порядок индекса) | «psytrance» числился алиасом и trance, и psytrance; одинаковые спаны в scan() убили бы друг друга |

Спаны scan() честно разводят составные жанры: «symphonic metal» ≠ «metal»,
«happy hardcore» ≠ «hardcore», «latin freestyle» ≠ «latin», «vocal jazz» ≠
«jazz» — более длинный хит поглощает короткий, ровно как «dream pop» ≠ «pop».

## Снятые устаревшие алиасы (README ресёрча, «дубли против существующих 26»)

- `trance` больше НЕ алиас `edm`, `industrial` — НЕ алиас `techno`,
  `shoegaze` — НЕ алиас `dream pop`: все трое — собственные семейства пакета
  (батч 0 и F);
- `metalcore` и `nu metal` (Н2 #51 алиасила их в heavy metal) — собственные
  семейства (батч G); `thrash`/`thrash metal`/`metal` остаются алиасами
  heavy metal — своих семей в пакете нет.

## Красное / известные ограничения

- Ложная тревога про «пустую atmosphere у 5 семей в index.json» из черновика
  кодировщика была ошибкой его же скрипта (регистр имён) — index.json полон,
  правки не потребовались.
- Прежний (Н2 #51) ключ `['метал','heavy metal']` ловит прилагательное
  «металлический» («металлический скрежет» даёт второй якорь жанра
  heavy metal). Семейство при этом резолвится верно — по первому тегу
  (индастриал раньше по позиции). Не регрессия этой поставки; чистка стема
  невозможна без границы слова для кириллицы — кандидат в отдельный фикс
  shortStem.
- Список из 142 семей удлиняет системный промт продюсера (~1.9 КБ) — в
  бюджет 1800 токенов ответа не входит (это вход), GLM переваривает.
- sim-30 не расширялся сценариями под новые семьи (README: «при желании») —
  покрытие семей живёт в check-music-brain секцией 21; расширение симуляции —
  по слову владельца перед A/B-прогоном.
