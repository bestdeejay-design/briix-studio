# Модели генерации музыки — ресерч на замену/апгрейд ace-step (23.11.2026)

Автор: координатор-агент (web-ресерч). Контекст: серия «Граница» показала потолок
ace-step; эталон качества владельца = архив dj1 (9705 треков, model_display_name
«FUZZ-2.0»).

## 1. FUZZ-2.0 ОПОЗНАН: это Riffusion (Producer.ai)

- **FUZZ-2.0 — флагман Riffusion** после ребрендинга Riffusion → **Producer.ai** (08.2025):
  варианты FUZZ-2.0 Pro / Raw; качество сравнимо с Suno v5 («Suno killer» в обзорах).
- dj1.ru, судя по format, использует **API-обёртку над Riffusion FUZZ-2.0** (агрегаторы
  типа AceDataCloud продают модель под тем же именем «FUZZ-2.0 Pro», $0.03–0.20/трек).
- Официальный публичный API Producer.ai не подтверждён (упоминания «one developer key»,
  детали непроверяемы).

## 2. Self-host (RTX 3050 8GB / P40 24GB)

| Модель | Вокал+лирика | VRAM | Лицензия | Русский вокал |
|---|---|---|---|---|
| ACE-Step 1.5 (текущая) | да | ~8 GB | v1 Apache 2.0; v1.5 — проверить | multilingual + комьюнити-LoRA |
| YuE/YuE2 | да, лучший структурный вокал open-source | 24 GB+ (P40 на грани) | CC-подобная, комм. — проверять | EN/ZH; RU плохо без файнтюна |
| DiffRhythm 2 | да, секунды на трек | 4–8 GB | комм. — проверить | EN/ZH; RU — файнтюн |

Суть: полноценный русский вокал с кастомной лирикой self-host — фактически только
ACE-Step (+LoRA на своём архиве); качество ниже FUZZ-2.0/Suno.

## 4. Рекомендации

- **«Советский поп-рок / космо-радио» стиль**: путь A — ACE-Step + **LoRA-файнтюн на
  своём архиве** (9705 треков = готовый датасет стиля владельца) — потенциально самый
  точный по стилю, $0/трек, но общее качество ниже FUZZ/Suno.
- **«Джангл + женский RU вокал» и коммерческое качество**: путь B — гибрид: Mureka API
  (официальный, дешёвый, RU официально) как массовый канал + FUZZ-2.0 Pro через
  агрегатор как «качество как в архиве».
- Экономика: $0.02–0.20/трек → 10k генераций/мес = $200–2000/мес; self-host окупается
  на больших объёмах.

## 5. Честные пробелы

- Условия/наличие официального API Producer.ai — непроверяемо.
- Что именно стоит за dj1.ru (у кого берёт FUZZ-2.0, с какими правами).
- Качество русского женского вокала Mureka/FUZZ — только репутация, нужен свой A/B.
- Лицензии ACE-Step 1.5 / YuE2 / DiffRhythm 2 — читать LICENSE в репозиториях.
- VRAM-бенчмарки YuE2 на P40 (Pascal может не завестись под современными кернелами).

## Топ-3 следующих шага

1. Проверить dj1-дамп/доступ: откуда дёргался FUZZ-2.0 — если доступ жив, это самый
   быстрый путь «то же качество, как в архиве».
2. A/B-тест: один промт («космический советский поп-рок», «джангл+женский RU вокал»)
   через ACE-Step 1.5, Mureka API и FUZZ-2.0 Pro — сравнить русский женский вокал.
3. Прочитать LICENSE ace-step 1.5 / YuE2; поставить эксперимент LoRA ace-step на
   подвыборке архива (P40).
