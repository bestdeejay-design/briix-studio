## 1. Замер: v1 против v2 на 20 брифах приёмки

| Метрика (доля брифов из 20) | v1 (`2026-11-14-studio-1`) | v2 (`2026-11-15-studio-2`) |
|---|---|---|
| есть ритм-слой | **2 / 20** | **20 / 20** |

Прогон воспроизводится: `node tools/check-music-brain.cjs` (печатает таблицу
20 брифов с длинами) и `git show 68a751e:studio/music-brain.js` для старой версии.

Живой кейс «Лови» v2.1 (бриф b01: *«тёмный психоделик-соул, глубокий мужской
голос шёпотом, 86 BPM, ночной город, без кульминации»*):

```
v1:  psychedelic soul, soul, male vocals, whisper, Russian lyrics, dark, night city, flat dynamics, loop-like
v2:  psychedelic soul, deep bass voice, whispered delivery, chest voice, register never rises,
     Russian lyrics, tight drum groove (kick + snare + ride), night city, tape saturation, analog warmth,
     flat dynamics, loop-like, dark
```

Разница, из-за которой звук был «очень бедный»: в v1 нет ни одного указания,
**что и как качает** (драм-секции), **как звучит голос** (только «whisper» —
не сказано, что это грудной регистр, который не уползает вверх) и **как
записан трек** (tape/analog появились только в v2 из жанрового дефолта).

## 2. Три дыры (подтверждены кодом)

### Дыра 1. Нет ритм-словаря

В v1 `INSTRUMENT_WORDS` содержит `['барабан', 'drums']` и `['бит', 'drums']` —
то есть drums попадали в caption **только если автор буквально написал «бит» или
«барабаны»**. Характера грува не было вообще, состава кита — тоже. Если задумка
описывает настроение и голос (типичный бриф владельца), ритм-секция исчезала.
Замер: 2 из 20 брифов получали ритм-слой, и оба — потому что содержали слово
«бит»/«барабаны».

### Дыра 2. `VOCAL_WORDS` описывает только пол

v1: `['женск','female vocals'] … ['шепот','whisper'] … ['фальцет','falsetto']`.
Подача и фактура не разделены: «шёпотом» давало `whisper` — существительное без
носителя, «хрип» не распознавался вовсе (в словаре его не было), «речитатив» →
`spoken word` был единственным исключением. Отдельного механизма против
фальцет-дрейфа не было: `POSITIVE` умел только `без фальцета → full-voice
delivery`, которого недостаточно (не сказано про регистр). Замер: 4 из 20.

### Дыра 3. Нет продакшн-цепочки и концепт-строки

v1 собирал продакшн только из `PROD_WORDS` (винил/плёнка/аналог/дождь/космос) —
это «атмосфера», а не «как записано». Жанровых дефолтов не было: если в задумке
не было слов о записи, слой исчезал (6 из 20 брифов имели хоть какой-то
продакшн-признак, и то случайно — через `rain atmosphere`/`space`).
Концепт-строки не было совсем.

## 3. Второстепенные находки (исправлены попутно)

| # | Находка | Риск | Решение v2 |
|---|---|---|---|
| A1 | Негативы обрабатывались регулярками `POSITIVE` без учёта контекста | «без фальцета» могло сосуществовать с тегом `falsetto` из словаря → смысл инвертировался | `negated()`: слово под отрицанием не становится позитивным тегом |
| A2 | Порядок блоков не гарантировал выживание важного при усечении | усечение по `MAX_TAGS` резало всё подряд, включая ритм | приоритеты блоков: ритм/голос/продакшн — 1, хвост — 3–5 |
| A3 | `'том' → toms` в словаре кита | ложное срабатывание на «шёпотом» («шепоТОМ») | `'том-том'`, `'томы'` |
| A4 | `'порт' → harbour` | ложные срабатывания («спорт», «паспорт») | `'портов'`, `'порт '`, `'в порту'` |
| A5 | Дубли тегов между блоками (`soul` + `psychedelic soul`, `bass` + `live bass guitar`, `flat dynamics` дважды) | трата бюджета, «размывание» веса | `dedupeTags()` + дедуп тег-в-теге |
| A6 | `PROD_WORDS` смешивал атмосферу и продакшн-цепочку | «night city» считался продакшном, жанровый дефолт не подставлялся | разделены `PROD_WORDS` / `ATMOS_WORDS` |
| A7 | `без реверберации` + жанровый дефолт `analog reverb` | противоречие в одном caption | при негативе реверба реверб-дефолты отфильтровываются |
| A8 | `без ударных` ничего не меняло | жанровый кит всё равно подставлялся | `NO_DRUMS` → `beatless drift` |

## 4. Что НЕ менялось (проверено)

- `buildTags(brief, options)` — та же сигнатура и те же поля `{tags, notes,
  source}`; `tags` остаётся строкой ≤ 240 символов, её проверяют
  `tools/check-assembly.cjs` и `tools/check-studio.cjs`.
- `buildLyricsSkeleton`, `detectBpm` — без изменений.
- Негативы → позитив (канон `model-acestep.md`) — сохранено и расширено.
- Языковое правило #109: отсутствие указания языка ≠ русский; дефолт `English
  lyrics` — сохранено.
- BPM не выдумывается: тег только при явном темпе.
- Обратимость подстановок: `notes` по-прежнему провенанс `{from, tag}`
  (плюс служебное поле `layer` для новых слоёв).
