## 0. Философия, под которую собран пакет

Владелец (§2 issue): **не «сколько всего напихать в промт», а «как правильно
указать важное»**, чтобы модель сама допела остальное. Слоёв может быть три, а не
двенадцать — но их должно хватать для полного погружения в ритм и атмосферу.

Отсюда критерий отбора слоя: слой попадает в caption, только если доказано, что
он (а) различает «сработавшие» и «не сработавшие» промты корпуса, (б) имеет
дешёвую детерминированную реализацию (словарь, без выдумывания), (в) не
конкурирует с другим слоем за внимание модели.

## 2. Что говорит каждый источник (цитаты)

**S1 (ACE-Step, статья).** Модель — diffusion + DCAE + линейный трансформер,
обученный с REPA (MERT / m-hubert). Среди заявленных свойств — «robustness to
diverse input formats for **both descriptive tags and lyrics**», то есть caption
принимается и как список тегов, и как описательный текст. Следствие для мозга:
нам не нужно выбирать между «тегами» и «фразой» — можно собирать гибрид, где
слой — это короткая фраза с составом (`tight drum groove (kick + snare + ride)`).

**S2 (код ACE-Step, решающий факт).** Caption кодируется umT5:

```python
# acestep/pipeline_ace_step.py
from transformers import UMT5EncoderModel, AutoTokenizer
...
def get_text_embeddings(self, texts, text_max_length=256):
    inputs = self.text_tokenizer(
        texts,
        ...
        truncation=True,
        max_length=text_max_length,
```

`truncation=True` — **тихое усечение**: всё, что длиннее 256 токенов caption,
модель не видит вообще. Для латиницы это порядка 700–900 символов. Значит:
1. Существующий лимит студии `MAX_TAGS = 240` — не «произвол», а консервативный
   запас; его можно оставить для компактного пути.
2. Полный продюсерский caption имеет смысл поднять, но не выше ~640 символов
   (≈170–190 токенов даже при плотной токенизации) — иначе верхние слои начнут
   отваливаться молча.
3. **Порядок блоков = приоритет.** При усечении теряется хвост, поэтому хвост
   должен быть самым необязательным (концепт, эпоха), а ритм/голос/продакшн —
   в начале.

**S3 (README ACE-Step).** v1.5 — актуальная ветка, LoRA-файнтюн официально
поддерживается; на инференсе можно подавать теги, описание или «сценарий
использования». Следствие: caption можно писать как «сцену» — но сцена должна
оставаться в рамках трёх слоёв, иначе превращается в рассказ.

**S4 (Udio, официальный гайд).** Рекомендация буквально: «Describe the **genre,
mood, tempo, instruments, and theme** in detail» + отдельно про вокал:
«Vocal gender / Vocal texture (clean, raspy, distorted) / Vocal style (sung, rap,
melodic rap)», примеры вроде «husky vocals». **Это независимое подтверждение
трёх наших слоёв и того, что характер вокала указывается отдельно от пола.**

**S5 (Suno, поля и вес).** Сводно по официальному поведению полей: Style-поле
несёт жанр/настроение/инструменты/вокал/продакшн, порядок важен («front-load»,
ранние теги весят больше), негативы — отдельным полем `Exclude Styles`
(в ACE-Step такого поля нет, S2/S8), рабочий диапазон 6–12 тегов; лимиты полей
меняются по версиям (1000 символов на v4.5+). Следствие: (а) порядок слоёв —
это не косметика; (б) перегруз тегами «размывает» вес ранних тегов; (в) негатив
переформулируем позитивно.

**S6 (Riffusion).** В Riffusion-пайплайне `negative_prompt` был полноценным
входом («positive and negative prompts are in equal footing»). Корпус владельца
целиком сгенерирован на FUZZ/Riffusion — отсюда в топ-промтах `no falsetto`,
`no climax`, `no reverb`. **Для ACE-Step эти запреты не работают (S2, S8)**:
их нужно переводить в утверждения, иначе смысл инвертируется.

**S7 (корпус, 8202).** Цифры ниже (§3).

**S8 (внутренний канон).** `model-acestep.md`: «негативного поля нет —
перефразировать позитивно», «теги, разумно ≤ 250 символов». `prompt-rules.md`:
порядок «жанр → инструменты → вокал → темп → настроение → эпоха/продакшн»,
5–10 точных дескрипторов. `prompts-by-genre.md` — топы по score, на которых
видно фактическую формулу 8 блоков.

## 4. Ответы на 5 вопросов §3

### Вопрос 1. Минимально-достаточный набор слоёв

**Ответ: пять ролевых блоков + якорь жанра + хвост. Три — мало, восемь — плато.**

Первая редакция этого пакета отвечала «три слоя» (голос / ритм / пространство).
Это был вывод из кандидатов issue §2, а не требование владельца: уточнение
(«я это просто упомянул, что может быть и не 12, а 3 — но это должен быть
полный трек со всем необходимым») получено 15.11, и замер по корпусу его
подтверждает.

Расширенный набор блоков, топ-100 против всего корпуса:

| Блок | топ-100 | корпус | lift |
|---|---|---|---|
| защита от дрейфа («only …», «without …», перефразированные позитивно) | 56 % | 15 % | **3,7×** |
| подача/регистр вокала | 65 % | 23 % | 2,9× |
| форма и энергия во времени (intro, breakdown, build, outro) | 32 % | 14 % | **2,3×** |
| роли инструментов (lead, carrier, texture, bed) | 55 % | 28 % | 1,9× |
| микс (середина, верх, ширина, глубина) | 39 % | 20 % | 1,9× |
| продакшн-цепочка | 66 % | 37 % | 1,8× |
| хук / запоминающаяся мелодия | 9 % | 6 % | 1,5× |
| тональность / лад | 2 % | 5 % | 0,4× |

Средний score по числу блоков (промты ≥ 80 символов): 1 — 15,8; 2 — 14,4;
3 — 19,9; 4 — 22,9; **5 — 30,2**; 6 — 27,0; 7 — 18,7; 8 — 26,7 (n = 58).
Пик — пять блоков; дальше плато и спад, что совпадает с правилом Suno
«6–12 тегов, дальше размывание» (S5) и с потолком 256 токенов (S2).

**Итоговая схема (v3):**

- **ANCHOR** — жанр/поджанр (+ эпоха, если названа);
- **L3 VOICE** — пол/регистр + подача + фактура + язык лирики;
- **L2 RHYTHM** — BPM + характер грува + состав кита + низ;
- **L1 SPACE** — инструменты **с ролями**, **микс** (середина/верх/ширина/глубина),
  атмосфера, продакшн-цепочка, место записи;
- **L4 ARRANGEMENT** — форма и энергия во времени (что входит, где разрыв,
  куда едет финал) — этого в «трёх слоях» не было вовсе;
- **TAIL** — динамика + настроение + концепт-строка;
- **GUARDS** — защита от дрейфа в позитивной форме (антифальцет, «без автотюна»,
  «без дисторшна», «только живой звук» и т. п.).

Тональность/лад (key/scale) **не добавляется**: в корпусе 2 % в топ-100 против
5 % по корпусу — признак не различает успех, а бюджет тратит.

Что это меняет по сравнению с «тремя слоями» в цифрах: блок «форма» в топ-100
встречается в 2,3 раза чаще, чем в корпусе, «роли инструментов» — в 1,9 раза,
«защита от дрейфа» — в 3,7 раза. Это и есть то «всё необходимое», без чего
трек звучит бедно: три слоя описывают, **из чего** трек, но не описывают,
**что в нём происходит** и **куда он не должен уехать**.

### Вопрос 2. Длина и плотность caption: где граница полезной детализации

**Ответ: польза растёт до ~400–650 символов, дальше — плато и риск тихого
усечения.**

- Медиана топ-100 — 402 символа, максимум среднего score — в корзине 400–700
  (27,3 против 14–16 у коротких), после 700 — спад (20,2).
- Технический потолок: 256 токенов umT5 (S2). 640 символов латиницы ≈ 170–190
  токенов — внутри потолка с запасом ~25–30 %.
- Практика Suno: 6–12 тегов, «front-load», перегруз >15–18 тегов не добавляет
  направления (S5).

**Решение для мозга:** два бюджета.
`MAX_TAGS = 240` — компактный путь студии (обратная совместимость #109,
его проверяют существующие vm-тесты);
`MAX_CAPTION = 640` — полный продюсерский caption (`buildCaption`), который
используется в бенчмарке и в следующем шаге подключения студии. Оба бюджета
укладываются в 256 токенов.

### Вопрос 3. Как формулируют ритм-секцию лучшие промты

**Ответ: «характер + носитель + состав кита в скобках», одной фразой.**

Из топ-промтов корпуса (S8, `prompts-by-genre.md`, score 407–448):

- `slow tight drum groove with ride cymbal` (Room 7, 448)
- `tight drum groove (kick + snare + ride)` (BREATH IS VOW, 407)
- `round deep hypnotic drum groove` (VELVET STATIC, трек 5)
- `intricate call-and-response drum pattern` (трек 4)
- `sparse electronic beat (no snare, only kick and hi-hat)` — пример негатива
  внутри состава, для ACE-Step переписывается позитивно.

Частоты: состав кита в скобках/перечислением — 25 % топ-100 против 14,5 %
корпуса; `808`/`909` — маркеры жанрового кита (808 — 1548 треков корпуса,
909 — 543).

**Решение:** ритм-слой собирается как `<характер> <грув> (<состав кита>)`,
где характер берётся из слов задумки (`плотный`, `медленный`, `ломаный`), а
недостающее — из жанрового профиля. Ритм-слой в caption есть **всегда**
(приёмка #20), потому что отсутствие описания кита — основная причина «бедной»
генерации («Лови» v2.1).

### Вопрос 4. Вокал: регистр / подача / фактура и борьба с фальцет-дрейфом

**Ответ: три отдельных признака + позитивный «страж регистра».**

- Корпус: `whisper` — 414 треков, `spoken word` — 173, `male baritone` — 546,
  `falsetto` — 112 (только 31 из них — в топ-500, положительный falsetto в
  топ-100 — 5 треков). При этом `no falsetto` — 91 трек: владелец исторически
  боролся с дрейфом запретом, а не указанием.
- Udio (S4): пол, фактура (clean / raspy / distorted) и подача (sung / rap /
  melodic rap) — три разных пункта официального гайда.
- Suno-практика (S5): «вокал без указания = случайный голос», поэтому пол и
  подача указываются всегда.

**Механика дрейфа (объяснение, а не факт из статьи):** при длинных секциях
модель «дотягивает» мелодию вверх, если регистр не задан как ограничение в
позитивной форме. Прямой запрет для ACE-Step недоступен (S2/S8), поэтому
используется утверждение: **`chest voice, register never rises`** — оно
описывает желаемое поведение, а не отсутствие.

**Решение:** `VOCAL_GENDER` (пол/регистр), `VOCAL_DELIVERY` (шёпот, речитатив,
spoken-sung, крик…), `VOCAL_TEXTURE` (хрип, gravel, бархат, придыхание,
фальцет…). Страж добавляется, когда задумка говорит о низком голосе
(«глубокий/низкий/бас/баритон») и явно не просит фальцет.

### Вопрос 5. Словесные формулы волновой динамики

**Ответ: работают, но только как короткие маркеры направления, и лучше — в
позитивной форме.**

Что реально есть в корпусе и в референс-альбоме владельца:

- `no climax` (79 треков) → позитивно `flat dynamics, loop-like` (канон S8);
- `steady energy`, `building tension without climax` (THE EDGE OF YES, 269);
- `soft dynamics with near-silent suspensions before drums re-enter`
  (SONIC-CONST в VELVET STATIC);
- `slow-building and emotionally tense groove` (When the screens go dark, 179);
- `waves of volume` (VELVET STATIC, трек 6), `intro-silence → … → silence`
  (FINAL TRANSMISSION).

Динамика — самый сильный lift в корпусе (29 % топ-100 против 7 %, 4,1×), но
встречается редко: это признак «автор писал сценарий», а не обязательный тег.

**Решение:** `DYNAMICS_WORDS` распознаёт «волнами», «нарастание», «почти
тишина», «без кульминации» и отдаёт короткий маркер
(`wave dynamics`, `near-silent suspensions before drums re-enter`,
`flat dynamics, loop-like`); в caption это хвост, который режется первым.

## 5. Утверждённая схема caption (вход в код)

```
ANCHOR  жанр (+ эпоха, если названа)
L3 VOICE   пол/регистр, подача, фактура, [язык лирики]        ← приоритет 1
L2 RHYTHM  BPM, <характер> <грув> (<состав кита>), низ        ← приоритет 1
L1 SPACE   инструменты + роли, микс, атмосфера, продакшн      ← приоритет 1–3
L4 ARRANGE форма/энергия: intro, breakdown, build, outro      ← приоритет 3
TAIL       динамика, настроение, «lyrics about …»             ← приоритет 3–5
GUARDS     защита от дрейфа в позитивной форме                ← приоритет 1
```

Порядок блоков в строке — как в топ-промтах корпуса:
`жанр → вокал → BPM → ритм-секция → инструменты → продакшн → настроение →
концепт`. Усечение по бюджету идёт с конца (хвост → эпоха → атмосфера →
инструменты), **ритм и голос не режутся никогда**.

Соответствие коду:

| Решение | Где в `studio/music-brain.js` |
|---|---|
| пять ролевых блоков + якорь + хвост | `composeLayers`, `rules.layerOrder` |
| ритм всегда | `RHYTHM_BY_GENRE`, `RHYTHM_FALLBACK`, приоритет 1 в `renderCaption` |
| вокал с характером | `VOCAL_GENDER / VOCAL_DELIVERY / VOCAL_TEXTURE`, дефолт `intimate delivery` |
| страж фальцета | `FALSETTO_GUARD = 'chest voice, register never rises'` |
| бюджеты 240 / 640 | `MAX_TAGS`, `MAX_CAPTION` |
| негативы только позитивно | `POSITIVE`, `NO_DRUMS`, `negated()` |
| роли / микс / форма / защиты | `ROLE_WORDS`, `MIX_WORDS`, `ARRANGEMENT_WORDS`, `GUARD_WORDS` |
| самопроверка слоёв | `selfCheck()` → `notes` |

## 6. Открытые вопросы (не блокируют поставку)

1. Влияние **порядка** тегов на ACE-Step не измерено публично (у Suno — измерено
   практикой). Мы приняли порядок корпуса; проверка — фаза 2 бенчмарка.
2. Лимит `256` токенов — из v1; в v1.5 конфигурация может отличаться
   (в репозитории код v1). Наш бюджет 640 символов оставляет запас, чтобы это
   расхождение не било.
3. Русскоязычные caption-словари (перевод задумки) — детерминированные; тонкие
   формулировки («вкрадчиво», «наотмашь») пока не распознаются и уходят в
   дефолт. Кандидат на следующую итерацию: расширение словарей по логам чатов.
