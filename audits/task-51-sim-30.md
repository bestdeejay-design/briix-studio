## Метод: настоящая студия, а не зеркало

Прогон — это НЕ vm-зеркало сборки (как check-assembly), а **реальный studio.js в
реальном Chromium** (Playwright) против фейкового media-bff на 127.0.0.1:

- все три пути пользователя: «Сгенерировать трек» из Simple (автолирика),
  «Тонко настроить» (ручная лирика), чат-наставник → черновик → «Сгенерировать»;
- chat-модель (автор песен / переводчик / наставник) отвечает сценарными
  скриптами; генерация аудио мгновенно ready — музыкальная модель НЕ участвует,
  её поведение вне скоупа (мы проверяем мозг и сборку);
- на каждом запросе фиксируются: что МОЗГ решил (перевод, семейство, слои,
  голос, язык), что УЕХАЛО В МОДЕЛЬ (POST /jobs: prompt, params.lyrics,
  language, title), что ПОЛЬЗОВАТЕЛЬ УВИДЕЛ (карточки предупреждений, бейджи);
- автопроверка инвариантов: prompt ≤640 и ASCII, без секционных тегов; язык —
  одно решение (тег caption ↔ params.language); брекеты EN и без дублей; текст
  лирики не переписан; авторский ASCII не тронут; title без имён; instrumental
  без лирики/языка; model=flash.

Лирика/переводы в моках написаны по механикам промтов (дословный припев, парные
куплеты) — ни одной чужой строки. 12 Simple + 3 Инструментал + 10 Advanced +
5 Наставник = 30.

## Находки и фиксы

### Н1 (починено): семейство для голоса/атмосферы резолвилось из исходника ДО перевода

`lyricStyleFamily` и голосовой слой считали семейство по `styleOf(исходная идея)`,
а не-ASCII идея проходила перевод ПОСЛЕ. Брекеты же сканируют финальный EN-caption
(#47) и семейство видели. Итог на RU-идеях, где жанр есть только в переводе:
**нейтральный голос + moodLine=null при оркестровых/балладных брекетах**.

- **02** «грустная песня на русском…» → «sad acoustic ballad…», брекеты балладные —
  голос нейтральный, атмосферы нет;
- **11** «эпичная киномузыка…» → брекеты orchestral — голос нейтральный;
- **08** «как у Metallica» → голос нейтральный «clean tone» на трэш-метале.

**Фикс (studio.js, createMusic):** перевод не-ASCII идеи выполняется ДО
автолирики и сборки (тот же translatePrompt, раньше по времени); семейство
резолвится цепочкой **черновик сессии → styleOf(исходник) → styleOf(перевод)**
и кормит голосовой слой, moodLine автолирики, якорь жанра и разметку
брекетов. Приоритет исходника сохранён: его жанровые слова мозг видит и так.

Проверка на живом UI: 02 → «Голос из стиля: ballad» + атмосфера «emotional
(ballad)»; 08 → «Голос из стиля: heavy metal» + «aggressive (heavy metal)»;
11 → «Голос из стиля: cinematic». Нейтральным остаётся только честный кейс 05
«кот» — жанра действительно нет.

### Н2 (починено): популярные жанры вне словаря — голос по умолчанию не в жанре

Metal, eurodance, jungle, «киномузыка» не резолвились ни из RU-стемов, ни из
EN (GENRE_WORDS их не знали): евродэнс и джангл получали generic-ритм
«steady drum groove», металл — поповый «clean tone», киномузыка — нейтральный
голос при оркестровых брекетах.

**Фикс (music-brain.js + producer-brain.js):** три новых семейства — **heavy
metal, eurodance, drum and bass** (23 → 26 семей). Профили голоса — дословно
из §2 справки владельца vocal-profile-vocabulary.md («classic heavy metal /
Metallica», «eurodance / Руки Вверх»), ритм/продакшн/атмосфера/брекеты — по
жанровой практике, как у остальных семей:

- GENRE_WORDS: RU-стемы (метал, евродэнс, джангл, драм-н-бейс, киномузык,
  саундтрек) + EN (metal/thrash/metalcore/nu metal, eurodance, jungle/dnb/
  drum and bass, soundtrack); имя «Metallica» жанром НЕ является (граница
  слова) — его переводит переводчик в «heavy metal», как и было;
- VOCAL_PROFILES: металл — gritty baritone + raspy aggressive + sung verses
  shouted into a full-throated chorus + guard «staying in the basement»;
  евродэнс — young male + bright boyish tenor + playful cheerful; dnb —
  soulful female lead. Правило 0 (тонкие мужские голоса) соблюдено;
- RHYTHM_BY_GENRE: джангл → «fast chopped breakbeats (chopped breakbeats,
  deep sub-bass)», евродэнс → four-on-the-floor + offbeat rave bass;
- брекеты: метал → группа (guitar solo/gang vocals), евродэнс и dnb →
  клубная динамика (дропы/райзеры);
- STYLE_FAMILIES наставника расширен — теперь он может вернуть новые семьи.

Проверка: 03/17 → брейкбиты вместо generic-грува; 25 → семейная решётка
металла поверх юзер-хинтов (growl); 08 → см. Н1.

### Н3 (починено): вырезание имени из середины названия и жёсткая формулировка на бытовых омонимах

- **24**: идея «рок в стиле Кино» + бытовое «кино» в лирике → название
  «Мы смотрели кино до утра» после вырезания имени превращалось в битое
  **«Мы смотрели до утра»** и уезжало в теги трека;
- **06**: бытовая строка «Hands up high…» матчится алиасом «Руки Вверх» →
  предупреждение звучало как факт утечки.

**Фикс (studio.js):**

- новое имя в title срезается только по КРАЮ («Кино — ночная песня» →
  «ночная песня»), свисающие предлоги подрезаются («Песня про кино» →
  «Песня»); из середины имя НЕ вырезается — название пересобирается
  цепочкой **край → первая чистая строка лирики → тема идеи без
  фразы-ссылки → семейство стиля**. Кейс 24 теперь даёт title
  **«Ночные окна»** (припев из лирики пользователя) вместо битой фразы;
  чистое название («В плену у джаза») не трогается;
- предупреждение об имени в лирике различает контекст: маркер ссылки
  («в стиле/как у/like») рядом с именем в той же строке → жёсткая
  формулировка (это отсылка); бытовое употребление («мы смотрели кино до
  утра», «hands up high») → мягкая («возможно, это обычное слово; если
  отсылка — уберите»);
- тот же edge-срез применён в guardMusicDraft (путь черновика наставника).

Юнит-покрытие: check-chat-draft — 8 новых ассертов на
stripArtistNameAtEdges / rebuildTitleWithoutNames (vm, без браузера).

### Н4 (инфо, by design): авторский advanced-промт остаётся без голосового профиля и guard-ов

16, 19–23: авторский ASCII-промт (16–32 символа) уходит как есть — без
семейного вокала, без guard-ов регистра, брекеты всё равно размечаются по
жанровым словам промта (19: dream pop-брекеты при промте «dream pop, 100
BPM»). Это правило #109 (авторский текст не переписываем) — просто
фиксируем: бейджа «Голос из стиля» на этом пути не бывает.

### Н5 (инфо, by design): лирика без секционных тегов уезжает без скелета и без брекетов

22: предупреждение «Структура лирики» есть, лирика уходит как текст без
`[Verse]/[Chorus]`, брекетов 0 — размечать нечего. Не блокирует — по решению
владельца (навязывать каркас нельзя).
