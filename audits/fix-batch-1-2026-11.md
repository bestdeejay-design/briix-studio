## 2. Новые ассерты в сюитах (регрессия закрыта)

`tools/check-studio.cjs` (49 проверок, все зелёные):
- `params.language === 'ru'` для кириллической лирики, `'en'` для ASCII, `undefined` для инструментала;
- `params.title === 'Город спит'` / `'City sleeps'` (не `[Verse]`);
- волна рисуется из **объекта** `{id, duration, peaks}` (fresh-карточка) и из **массива** (100 legacy-restore);
- инструментальные стадии `model-warmup → generating` приходят в индикатор;
- `✕` шлёт `POST /jobs/{id}/cancel` (мок обзавёлся маршрутом);
- одновременно играет ≤ 1 трека (эксклюзивный транспорт).

`tools/check-wait-phrases.cjs` (переписана, 11 проверок): пулы 40+ с instrumental-стадиями, малые пулы без повторов подряд, история переживает reload, ротация 4–6 с, reduced-motion, живая джоба со стадией `generating` и подписью «генерация», серверная отмена, чат-фраза до первого чанка.
